# Notes de version v1.5.0 de Media Harvest

Version anglaise : [English Release Notes](https://github.com/VBlackJack/media-harvest/blob/v1.5.0/docs/release-notes/v1.5.0.md)

Media Harvest v1.5.0 ajoute une file de téléchargements par lots résiliente dans le Service Worker, l'exclusion des boutons intégrés par domaine, le téléchargement direct en SRT, le spool disque OPFS sur le Live DVR, la continuité temporelle audio en écriture disque et le workflow de release automatisé.

## Points forts

- **File de lots en arrière-plan :** Ajout de `src/background/batch_queue.js` (`START_BATCH_QUEUE`, `CANCEL_BATCH_QUEUE`, `GET_BATCH_QUEUE_STATE`, `BATCH_QUEUE_PROGRESS`) dans le Service Worker pour poursuivre les téléchargements en lot même lorsque la popup se ferme.
- **Live DVR OPFS et continuité audio disque :** Connexion du spool disque OPFS dans `recordLiveHlsBlob` (`src/offscreen/offscreen.js`) avec nettoyage automatique à la révocation du Blob, et suivi monotone `baseMediaDecodeTime` / `startSequenceNumber` pour les segments audio ADTS et WebM-Opus dans `streamDualMixedToWritable` (`src/saver/stream_saver.js`).
- **Téléchargement SRT en un clic :** Ajout de boutons `SRT` dédiés sur les pistes de sous-titres de flux et les cartes `.vtt` directes (`src/popup/media_card.js`, `src/popup/popup.js`).
- **Exclusions d'overlay par domaine :** Ajout du champ `disabledOverlayHosts` dans Options (`src/options/options.html`, `src/options/options.js`, `src/shared/settings.js`) et de `isHostDisabledInSettings` (`src/content/overlay_common.js`) pour désactiver les boutons intégrés sur des domaines ciblés et leurs sous-domaines.
- **Pipeline de release automatisé :** Ajout de `.github/workflows/release.yml` (déclenché sur tag `v*`) et de `npm run package:firefox` dans `.github/workflows/ci.yml`.

## Vérification

- `npm run check` : Vérifications syntaxe, i18n, manifeste et typographie réussies (87 fichiers + vérification AST Python).
- `npm test` : 171/171 tests unitaires et d'intégration MV3 réussis.
- `npm run package` et `npm run package:firefox` : Archives ZIP déterministes Chromium et Firefox MV3 générées et vérifiées.
