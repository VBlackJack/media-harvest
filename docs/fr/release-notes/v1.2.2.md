# Notes de version v1.2.2 de Media Harvest

Version anglaise : [English Release Notes](https://github.com/VBlackJack/media-harvest/blob/v1.2.2/docs/release-notes/v1.2.2.md)

Media Harvest v1.2.2 corrige le téléchargement via le bouton intégré sur X (Twitter) et les sites vidéo lorsque les sous-playlists audio (`mp4a`) ou vidéo seule (`avc1`) étaient capturées après la playlist maître.

## Points forts

- **Priorité à la playlist maître HLS :** Mise à jour de `handleTweetVideoDownload`, `handleSiteVideoDownload` et `findMatchingStreamForDirectUrl` (`src/background/service_worker.js`) pour classer la playlist maître avant les sous-playlists de rendu codec/résolution et écarter les flux audio seuls (`mp4a`, `aac`, `audio`, `DASH_AUDIO`).
- **Repli avec piste audio soeur :** Si seules les sous-playlists vidéo et audio séparées ont été interceptées sans playlist maître, `service_worker.js` associe la sous-playlist audio correspondante via `audioUrl` et `resolveStreamPlan` (`src/offscreen/offscreen.js`) les assemble ensemble.
- **Couverture vérifiée :** Suite automatisée portée à 144 tests unitaires et d'intégration (`86.81 %` de couverture lignes).

## Vérification

- `npm run check` : Vérifications syntaxe, i18n, manifeste et typographie réussies (68 fichiers + scripts compagnon).
- `npm test` : 144/144 tests unitaires et d'intégration MV3 réussis.
- `npm run test:e2e` : Suite Chromium MV3 E2E validée sous GitHub Actions `ubuntu-latest`.
