# Notes de version v1.3.0 de Media Harvest

Version anglaise : [English Release Notes](https://github.com/VBlackJack/media-harvest/blob/v1.3.0/docs/release-notes/v1.3.0.md)

Media Harvest v1.3.0 introduit une refactorisation modulaire de la base de code, la protection des playlists maître lors du défilement, le streaming disque direct (>512 Mo) pour WebM double piste et conteneurs mixtes, l'alignement temporel ABR des flux MSE, un menu rapide qualité/audio sur les boutons vidéo intégrés et un historique des téléchargements récents dans la popup.

## Points forts

- **Menu rapide qualité et audio sur les boutons intégrés :** Ajout d'un sélecteur compact à côté du bouton sur X (`src/content/x_overlay.js`) et sur les lecteurs vidéo sociaux/HTML5 génériques (`src/content/site_overlay.js`) pour lancer un téléchargement Meilleure qualité, Compact/plus léger ou Audio seul en un clic.
- **Tiroir des téléchargements récents :** Ajout d'un panneau dépliable dans la popup (`src/popup/history_controller.js`) conservant les 15 derniers téléchargements dans `chrome.storage.local` avec statut, bouton Relancer en un clic et bouton Effacer.
- **Protection des playlists maître au défilement :** Extraction de `src/shared/stream_selector.js` avec `mergeCapturedMediaEntry`, préservant les playlists maître interceptées lorsque le plafond par onglet déclenche une éviction.
- **Streaming disque direct >512 Mo étendu :** Ajout des réessais HTTP transitoires (`fetchWithRetry`), de l'écriture WebM double piste (`streamDualWebmToWritable`) et du muxage mixte sur disque (`streamDualMixedToWritable` pour TS/ADTS/fMP4+WebM Opus) dans `src/saver/stream_saver.js`.
- **Alignement temporel ABR MSE :** Ajout de `alignFmp4MseFragments` (`src/shared/fmp4_muxer.js`) et du rognage `alignAbr` (`src/shared/webm_muxer.js`) dans `src/offscreen/offscreen.js` afin de garder vidéo et audio synchronisés après un changement de résolution en cours de lecture.
- **Architecture allégée :** Extraction de `src/offscreen/image_processor.js` et `src/popup/lightbox_controller.js` ainsi que mutualisation de `decodeBase64ToBytes` dans `src/shared/hls_crypto.js`.

## Vérification

- `npm run check` : Vérifications syntaxe, i18n, manifeste et typographie réussies (75 fichiers + scripts compagnon).
- `npm test` : 159/159 tests unitaires et d'intégration MV3 réussis (`87.56 %` de couverture lignes).
- `npm run test:e2e` : Suite Chromium MV3 E2E validée sous GitHub Actions `ubuntu-latest`.
