# Notes de version v1.3.1 de Media Harvest

Version anglaise : [English Release Notes](https://github.com/VBlackJack/media-harvest/blob/v1.3.1/docs/release-notes/v1.3.1.md)

Media Harvest v1.3.1 supprime les erreurs `Uncaught Error: Extension context invalidated.` qui apparaissaient dans les onglets déjà ouverts (comme YouTube ou X) lors d'un rechargement ou d'une mise à jour de l'extension.

## Points forts

- **Protection du pont MSE (`mse_bridge.js`) :** Encapsulation de tous les appels `chrome.runtime.sendMessage`, `chrome.storage.sync.get` (avec contrôle de `chrome.runtime.lastError`), `chrome.storage.onChanged` et `sendResponse` via `sendRuntimeMessageSafe` et `try/catch` dans `src/content/mse_bridge.js`, plus gestion propre des échecs de fragments `EXPORT_CHUNK` via `pending.queueError` sans rejet de promesse non capturé.
- **Durcissement des boutons intégrés :** Protection des appels d'annulation et de lecture de paramètres dans `src/content/x_overlay.js` et `src/content/site_overlay.js` contre les contextes invalidés.
- **Couverture vérifiée :** Ajout d'un test dédié dans `tests/mse_capture.test.js` portant la suite à `160/160` tests réussis.

## Vérification

- `npm run check` : Vérifications syntaxe, i18n, manifeste et typographie réussies (75 fichiers + scripts compagnon).
- `npm test` : 160/160 tests unitaires et d'intégration MV3 réussis.
- `npm run test:e2e` : Suite Chromium MV3 E2E validée sous GitHub Actions `ubuntu-latest`.
