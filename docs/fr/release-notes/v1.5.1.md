# Notes de version v1.5.1 de Media Harvest

Version anglaise : [English Release Notes](https://github.com/VBlackJack/media-harvest/blob/v1.5.1/docs/release-notes/v1.5.1.md)

Media Harvest v1.5.1 aligne l'ensemble de la documentation bilingue (README et guides d'architecture) sur toutes les fonctionnalités livrées dans les versions v1.4.0 et v1.5.0.

## Points forts

- **Parité des README bilingues :** Mise à jour de `README.md` et `README.fr.md` avec la file de lots en arrière-plan, le spool disque OPFS pour la capture d'onglet et le Live DVR, les sous-titres SRT en un clic, les exclusions d'overlay par domaine (`disabledOverlayHosts`), le support DASH multi-Period et LL-HLS, la navigation clavier et la réinitialisation des couleurs de Lightbox Pro, l'empaquetage Firefox MV3 (`npm run package:firefox`) et le workflow de release GitHub automatisé.
- **Parité des guides d'architecture :** Mise à jour de `docs/ARCHITECTURE.md` et `docs/fr/ARCHITECTURE.md` avec tous les nouveaux modules Service Worker, Offscreen, scripts de contenu et modules partagés (`batch_queue.js`, `companion_client.js`, `download_history.js`, `opfs_spool.js`, `tab_capture.js`, `audio_transcoder.js`, `overlay_common.js`, `stream_planner.js`, `hls_crypto.js`, `subtitle_utils.js`), clés de stockage session/local, contrats de messages et isolation des émetteurs.

## Vérification

- `npm run check` : Vérifications syntaxe, i18n, manifeste et typographie réussies (87 fichiers + vérification AST Python).
- `npm test` : 171/171 tests unitaires et d'intégration MV3 réussis.
- `npm run package` et `npm run package:firefox` : Archives ZIP déterministes Chromium et Firefox MV3 générées et vérifiées.
