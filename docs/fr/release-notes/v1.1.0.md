# Notes de version v1.1.0 de Media Harvest

Version anglaise : [English Release Notes](../../release-notes/v1.1.0.md)

La version 1.1.0 de Media Harvest introduit l'integration d'un compagnon natif avec yt-dlp, la capture MediaSource (MSE), des surcouches modulaires pour les principaux reseaux sociaux, la gestion dediee des regles declarativeNetRequest, des sous-composants pour la fenetre contextuelle et un script de creation d'archive zip sans dependance.

## Points forts

- Compagnon Native Messaging : hote externe facultatif encapsulant yt-dlp et ffmpeg pour les flux necessitant une extraction externe, avec installateurs pour Windows (PowerShell), Linux et macOS (shell POSIX).
- Capture MediaSource (MSE) : extraction propre des flux audio et video dynamiques grace a l'interception dans le monde MAIN et au relais vers le monde ISOLATED.
- Surcouches sociales universelles : boutons et menus de telechargement integres aux pages YouTube, Instagram, TikTok, Reddit, Bluesky, Facebook, Vimeo, Dailymotion, Twitch et LinkedIn.
- Raccourci clavier : ouverture immediate de la fenetre contextuelle par Alt+Shift+M (Option+Shift+M sous macOS).
- Architecture modulaire : decoupage du gestionnaire de lots, du rendu des cartes media, du lecteur d'apercu et du gestionnaire de regles declarativeNetRequest en modules distincts.
- Creation de paquets pour la distribution : script autonome generant une archive zip prete a l'emploi avec empreinte SHA-256 via la commande `npm run package`.
- Couverture de tests : passage a 94 tests automatises repartis sur 24 suites de tests, avec 87% de couverture de code.

## Details des changements

### Hote compagnon natif
- Ajout de `companion/media_harvest_host.py` avec protocole standard stdin/stdout JSON.
- Ajout de `companion/install_companion.ps1` pour l'enregistrement du manifeste dans le registre Windows.
- Ajout de `companion/install_companion.sh` pour l'installation du manifeste sous Linux et macOS.
- Detection automatique du compagnon, verification des binaires et gestion du repli dans la page d'options.

### Capture des flux et des medias
- Ajout de `src/content/mse_hook.js` et `src/content/mse_bridge.js` pour intercepter les segments injectes dans SourceBuffer.
- Application stricte du plafond de memoire tampon a 512 Mo avec verification a chaque segment dans le document d'arriere-plan.
- Detection des pistes de sous-titres, extraction WebVTT et categorie de filtrage dediee.

### Interface utilisateur
- Extraction de `src/popup/batch_runner.js` pour gerer les telechargements groupes avec suivi de progression et annulation.
- Extraction de `src/popup/media_card.js` pour l'affichage et le cycle de vie des cartes d'elements.
- Extraction de `src/popup/preview_player.js` pour la lecture video inline.
- Ajout de `src/content/site_overlay.js` et `src/content/site_overlay.css` prenant en charge plusieurs adaptateurs avec positionnement personnalise.
- Boite de confirmation avant le lancement d'un lot important (10 elements ou plus).
- Bouton de reinitialisation rapide lorsqu'aucun resultat ne correspond aux filtres actifs.

### Service worker et regles reseau
- Extraction de `src/background/dnr_manager.js` pour la gestion dynamique des regles declarativeNetRequest (reecriture de referer et en-tetes).
- Simplification de `src/background/service_worker.js` autour du routage des messages et de la gestion des telechargements.

### Outils de construction et assurance qualite
- Ajout de `scripts/package_extension.mjs` et ajout du script npm `package`.
- Mise a jour de l'integration continue GitHub Actions pour tester l'environnement Python 3.
- Ajout des tests unitaires pour l'hote compagnon, le gestionnaire de lots, le gestionnaire DNR, le scanner DOM, la surcouche et le generateur d'archive.
