# Media Harvest v1.3.0 Release Notes

Media Harvest v1.3.0 delivers modular architecture refactoring, master playlist eviction protection on scrolling timelines, dual-track WebM and mixed-container direct disk streaming (>512 MB), MSE ABR temporal alignment, inline overlay quality/audio selectors, and a popup Recent Downloads history drawer.

## Highlights

- **Overlay Quality & Audio Quick Menu:** Added a compact menu toggle next to the X (`src/content/x_overlay.js`) and social/generic HTML5 video overlays (`src/content/site_overlay.js`) to trigger Best quality, Compact/lowest bitrate, or Audio-only downloads in one click without changing global defaults.
- **Recent Downloads History Drawer:** Added a collapsible history panel in the popup (`src/popup/history_controller.js`) persisting the latest 15 downloads in `chrome.storage.local` with status badges, one-click Retry, and Clear controls.
- **Timeline Master Playlist Protection:** Extracted `src/shared/stream_selector.js` with `mergeCapturedMediaEntry`, keeping captured root master playlists pinned when high-volume scrolling exceeds the per-tab media limit.
- **Expanded >512 MB Direct Disk Streaming:** Added transient fetch retries (`fetchWithRetry`), dual-track WebM DASH writing (`streamDualWebmToWritable`), and mixed TS/ADTS/fMP4+WebM Opus disk streaming (`streamDualMixedToWritable`) in `src/saver/stream_saver.js`.
- **MSE ABR Resolution-Switch Alignment:** Added `alignFmp4MseFragments` (`src/shared/fmp4_muxer.js`) and `alignAbr` WebM cluster trimming (`src/shared/webm_muxer.js`) in `src/offscreen/offscreen.js` to keep audio and video aligned when players switch bitrate mid-playback.
- **Cleaner Modular Structure:** Extracted `src/offscreen/image_processor.js` and `src/popup/lightbox_controller.js` alongside shared base64 byte decoding in `src/shared/hls_crypto.js`.

## Verification

- `npm run check`: Syntax, i18n, manifest, and typography checks passed (75 files + companion scripts).
- `npm test`: 159/159 automated unit and mocked MV3 integration tests passed (`87.56%` line coverage).
- `npm run test:e2e`: Chromium MV3 E2E suite verified on GitHub Actions `ubuntu-latest`.
