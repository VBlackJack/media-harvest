# Media Harvest v1.4.0 Release Notes

Media Harvest v1.4.0 delivers a full security, reliability, streaming, and architecture upgrade across the extension and Native Messaging companion.

## Highlights

- **Security and MV3 Lifecycle Hardening:** Replaced `window.postMessage` data traffic between `mse_hook.js` and `mse_bridge.js` with a private `MessageChannel` handshake and global SPA memory caps; isolated privileged service worker and offscreen handlers from content scripts; persisted session DNR rules with tab-scoped Stream Saver cleanup; added `OFFSCREEN_GET_ACTIVE_BUILDS` keep-alive checks before closing the offscreen document.
- **Media Integrity and Parser Fixes:** Fixed inverted `trun.data_offset` adjustment on multi-`traf` fMP4 audio extraction (`fmp4_muxer.js`), hardened SVG sanitization and UTF-8 decoding (`svg_utils.js`, `dom_scanner.js`), fixed XML double-unescaping (`dash_parser.js`), ADTS sync/sample-rate edge cases (`adts_transmuxer.js`), mixed MSE `trun.data_offset` (`mixed_mse_muxer.js`), RFC 7845 Opus channel clamping (`ogg_opus_muxer.js`), and added per-request timeouts and exponential backoff in `stream_saver.js`.
- **Advanced Streaming and Large Media:** Added DASH multi-Period concatenation and `SegmentBase` support, dynamic HLS `#EXT-X-MAP` tracking and LL-HLS `#EXT-X-PART` support, OPFS disk-backed chunk spooling (`opfs_spool.js`) for long Tab Capture recordings, zero-copy part-based ZIP assembly, and WebVTT-to-SRT subtitle conversion (`subtitle_utils.js`).
- **Companion Host Reliability:** Added real wall-clock timeout enforcement, live `cancel` support with full process-tree termination, `%` template injection and Windows reserved name guards, Edge cookie detection, and safe JSON generation in `install_companion.sh`.
- **UX, Accessibility, and Packaging:** Added Lightbox gallery `ArrowLeft`/`ArrowRight` navigation, SVG color reset, focus trap/restoration, WCAG AA contrast fixes, accessible keyboard overlay menus (`overlay_common.js`), debounced search and 40-card pagination, deterministic sorted ZIP builds, and a Firefox MV3 packaging target (`--target firefox`).

## Verification

- `npm run check`: Syntax, i18n, manifest, and typography checks passed (85 files + companion Python AST check).
- `npm test`: 169/169 automated unit and mocked MV3 integration tests passed.
- `npm run package`: Deterministic Chromium and Firefox MV3 ZIP archives built and verified.
