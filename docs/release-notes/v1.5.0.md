# Media Harvest v1.5.0 Release Notes

Media Harvest v1.5.0 introduces resilient Service Worker batch queues, per-domain overlay exclusions, one-click SRT subtitle actions, OPFS disk spooling for Live DVR, continuous direct-to-disk audio timestamps, and automated GitHub release packaging.

## Highlights

- **Resilient Background Batch Queue:** Added `src/background/batch_queue.js` (`START_BATCH_QUEUE`, `CANCEL_BATCH_QUEUE`, `GET_BATCH_QUEUE_STATE`, `BATCH_QUEUE_PROGRESS`) inside the Service Worker so batch downloads continue cleanly even if the popup closes.
- **OPFS Live DVR and Continuous Disk Audio Timestamps:** Wired OPFS disk-backed chunk spooling into `recordLiveHlsBlob` (`src/offscreen/offscreen.js`) with automatic cleanup on Blob revocation, and added monotonic `baseMediaDecodeTime` / `startSequenceNumber` tracking across incremental ADTS and WebM-Opus segments in `streamDualMixedToWritable` (`src/saver/stream_saver.js`).
- **One-Click SRT Subtitle Downloads:** Added dedicated `SRT` buttons on stream subtitle rows and direct `.vtt` cards (`src/popup/media_card.js`, `src/popup/popup.js`) backed by client-side WebVTT-to-SRT conversion.
- **Per-Domain Overlay Exclusions:** Added `disabledOverlayHosts` in Options (`src/options/options.html`, `src/options/options.js`, `src/shared/settings.js`) and `isHostDisabledInSettings` (`src/content/overlay_common.js`) to disable inline download buttons on chosen domains and their subdomains.
- **Automated Release Pipeline:** Added `.github/workflows/release.yml` (tag-triggered `v*` build and artifact upload) and `npm run package:firefox` in `.github/workflows/ci.yml`.

## Verification

- `npm run check`: Syntax, i18n, manifest, and typography checks passed (87 files + companion Python AST check).
- `npm test`: 171/171 automated unit and mocked MV3 integration tests passed.
- `npm run package` and `npm run package:firefox`: Deterministic Chromium and Firefox MV3 ZIP archives built and verified.
