# Media Harvest v1.3.1 Release Notes

Media Harvest v1.3.1 eliminates `Uncaught Error: Extension context invalidated.` runtime exceptions raised in already-open tabs (such as YouTube or X) when the extension is reloaded or updated.

## Highlights

- **Invalidated Context Guard in `mse_bridge.js`:** Wrapped all `chrome.runtime.sendMessage`, `chrome.storage.sync.get` (including `chrome.runtime.lastError`), `chrome.storage.onChanged`, and `sendResponse` calls with `sendRuntimeMessageSafe` and `try/catch` guards in `src/content/mse_bridge.js`, and handled async `EXPORT_CHUNK` append failures inside `pending.queueError` cleanly without unhandled promise rejections.
- **Content Overlay Hardening:** Guarded cancel and storage calls in `src/content/x_overlay.js` and `src/content/site_overlay.js` against invalidated extension contexts.
- **Verification Coverage:** Added unit test assertions in `tests/mse_capture.test.js` bringing the suite to `160/160` passing tests.

## Verification

- `npm run check`: Syntax, i18n, manifest, and typography checks passed (75 files + companion scripts).
- `npm test`: 160/160 automated unit and mocked MV3 integration tests passed.
- `npm run test:e2e`: Chromium MV3 E2E suite verified on GitHub Actions `ubuntu-latest`.
