# Media Harvest v1.1.0 Release Notes

Media Harvest v1.1.0 introduces native companion integration with yt-dlp, MediaSource (MSE) capture, modular overlays across major social platforms, dedicated declarativeNetRequest rule management, popup subcomponents, and a zero-dependency packaging pipeline.

## Highlights

- Native Messaging Companion: Optional external companion host wrapping yt-dlp and ffmpeg for media requiring external extractors, with installers for Windows (PowerShell), Linux, and macOS (POSIX shell).
- MediaSource (MSE) Capture: Clean streaming audio and video extraction from dynamic players via MAIN-world hooking and ISOLATED-world message bridging.
- Universal Social Overlays: Modular in-page download buttons and menus across YouTube, Instagram, TikTok, Reddit, Bluesky, Facebook, Vimeo, Dailymotion, Twitch, and LinkedIn.
- Keyboard Shortcut: Instant popup access via Alt+Shift+M (Option+Shift+M on macOS).
- Modular Architecture: Extracted batch runner, media card renderer, preview player, and declarativeNetRequest manager into decoupled modules.
- Production Packager: Standalone packaging script generating distribution zip archives with SHA-256 integrity checksums.
- Test Coverage: Expanded test suite to 94 tests across 24 test suites with 87% line coverage.

## What is Changed

### Native Companion Host
- Added `companion/media_harvest_host.py` with standard stdin/stdout JSON framing.
- Added `companion/install_companion.ps1` for Windows registry host registration.
- Added `companion/install_companion.sh` for Linux and macOS manifest placement.
- Added connection detection, probe capabilities, and fallback handling in the options page.

### Media Capture and Streaming
- Added `src/content/mse_hook.js` and `src/content/mse_bridge.js` for intercepting MSE SourceBuffer chunks.
- Enforced 512 MB memory threshold with streaming chunk limits in offscreen document.
- Added subtitle track detection, WebVTT extraction, and category filtering.

### Popup and Content UI
- Extracted `src/popup/batch_runner.js` for handling sequential multi-item downloads with progress reporting and abort support.
- Extracted `src/popup/media_card.js` for item card rendering and state lifecycle.
- Extracted `src/popup/preview_player.js` for inline video playback.
- Added `src/content/site_overlay.js` and `src/content/site_overlay.css` supporting multiple site adapters with custom positioning.
- Added confirmation dialog before starting large batch downloads (10 items or more).
- Added filter reset button when current search or category yields no results.

### Background and Network Rules
- Extracted `src/background/dnr_manager.js` for declarativeNetRequest dynamic referer and header rewriting.
- Streamlined `src/background/service_worker.js` around messaging, downloads, and lifecycle routing.

### Build and Quality Assurance
- Added `scripts/package_extension.mjs` and `npm run package` command.
- Updated GitHub Actions CI to include Python 3 testing environment.
- Added unit tests for companion host, batch runner, DNR manager, DOM scanner, site overlay, and package generator.
