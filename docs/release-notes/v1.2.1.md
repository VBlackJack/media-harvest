# Media Harvest v1.2.1 Release Notes

Media Harvest v1.2.1 is a focused bug-fix release resolving missing audio tracks across WebM DASH/MSE captures, separate ADTS `.aac` HLS audio renditions, split fMP4 streams, File System Access disk saves over 512 MB, and social/site overlay video downloads.

## Highlights

- **Dual-Track WebM Muxing (DASH & MSE):** Added a pure-JS EBML/Matroska muxer (`src/shared/webm_muxer.js`) with `TrackNumber`/`SimpleBlock` remapping and `TimestampScale` alignment, restoring sound on split WebM DASH streams and WebM+WebM MSE recordings.
- **ADTS `.aac` Separate HLS Audio Support:** Replaced failing raw-ADTS `mux.js` calls with a dedicated ADTS parser and ISO BMFF `'soun'` fMP4 builder (`src/shared/adts_transmuxer.js`), including ID3v2-prefixed segments and HLS masters missing `AUDIO=` group attributes.
- **fMP4 Offset Normalization:** Fixed silent or corrupted merged MP4 outputs by rewriting `tfhd` `base-data-offset-present` (`0x000001`) to `default-base-is-moof` (`0x020000`), adjusting `trun.data_offset`, and filtering stray non-`'soun'` tracks from audio init segments (`src/shared/fmp4_muxer.js`).
- **Over-Cap (>512 MB) Audio-Preserving Disk Streaming:** Updated `src/saver/stream_saver.js` so dual-track fMP4 HLS/DASH playlists preserve their separate audio track when written straight to disk.
- **Overlay Split-Stream & Companion Audio Pairing:** Prevented in-page download overlays (`src/background/service_worker.js`) from picking video-only URLs (such as `DASH_720.mp4`) over matching muxed manifests or paired `DASH_AUDIO_*` streams, and forwarded `progressiveMux` cleanly into offscreen assembly.

## Verification

- `npm run check`: Syntax, i18n, manifest, and typography checks passed (68 files + companion scripts).
- `npm test`: 143/143 automated unit and mocked MV3 integration tests passed.
- `npm run test:e2e`: Chromium MV3 E2E suite verified on GitHub Actions `ubuntu-latest`.
