# Media Harvest v1.5.1 Release Notes

Media Harvest v1.5.1 brings complete bilingual documentation parity for all v1.4.0 and v1.5.0 capabilities across the project README and architecture guides.

## Highlights

- **Bilingual README Parity:** Updated `README.md` and `README.fr.md` with background batch queues, OPFS disk spooling for Tab Capture and Live DVR, one-click SRT subtitles, per-domain overlay exclusions (`disabledOverlayHosts`), DASH multi-Period and LL-HLS support, Lightbox Pro keyboard navigation and color reset, Firefox MV3 packaging (`npm run package:firefox`), and the automated GitHub release workflow.
- **Bilingual Architecture Parity:** Updated `docs/ARCHITECTURE.md` and `docs/fr/ARCHITECTURE.md` with all new Service Worker, Offscreen, Content Script, and shared modules (`batch_queue.js`, `companion_client.js`, `download_history.js`, `opfs_spool.js`, `tab_capture.js`, `audio_transcoder.js`, `overlay_common.js`, `stream_planner.js`, `hls_crypto.js`, `subtitle_utils.js`), session/local storage keys, message contracts, and sender isolation details.

## Verification

- `npm run check`: Syntax, i18n, manifest, and typography checks passed (87 files + companion Python AST check).
- `npm test`: 171/171 automated unit and mocked MV3 integration tests passed.
- `npm run package` and `npm run package:firefox`: Deterministic Chromium and Firefox MV3 ZIP archives built and verified.
